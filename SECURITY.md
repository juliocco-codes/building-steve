# Security and privacy

A career workspace can expose compensation, performance feedback, future plans, private conversations, immigration matters, and information about employers or colleagues.

Never commit a completed `USER.md`, direction, plan, decision log, transcript, draft application, salary document, contact list, credential, or private company file. Review the complete Git diff for names, organizations, email addresses, figures, dates, local paths, tokens, and quoted conversations.

Steve should have no ability to contact people, submit forms, publish, or change external systems. Drafting and analysis are permitted; external action requires the user in a separate, explicit step.
